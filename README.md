# Nicole

> _「咳咳……作为天使，用 Markdown 撰写小说，很、很合理吧？」_
>
> _——面对旅人的好奇与疑惑，某笨蛋魔女羞红着脸如是说道。_

A what-you-see-is-what-you-get Markdown editor, built with [Microsoft.UI.Reactor](https://github.com/microsoft/microsoft-ui-reactor). It combines with a native WinUI 3 shell and a core editor leverages [CodeMirror](https://codemirror.net/), which receives user inputs and instantly renders Markdown elements once the cursor leaving from just-edited ones.

## Build from source code

Make your computer have these components installed before building Nicole:

- [.NET SDK](https://dotnet.microsoft.com/en-us/)
- [Bun](https://bun.com/)
- [WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2) (Optional, if your computer hasn't installed it)
- [winapp CLI](https://learn.microsoft.com/en-us/windows/apps/dev-tools/winapp-cli/) (Recommended, if you want to simplify building steps)
